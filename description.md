## Project Specs

Se quiere realizar una aplicación donde un usuario pueda subir regalos para que otros usuarios puedan coger la idea.

Todos los usuarios tienen que registrarse para poder acceder a la plataforma

Cualquier usuario puede subir ideas de regalos. Estos regalos tendran los siguientes datos:

- Nombre del regalo 
- Precio aproximado
- Fotografia (imagen a subir) (opcional)
- Descripción (opcional)
- Enlace al producto (opcional)

Cada usuario tendra un enlace publico donde estaran todos los regalos que ha creado. Este enlace se podrá compartir. Los usuarios no registrados podrán ver también la lista de regalos 

Cualquier usuario registrado podrá ver la lista de regalos de otro usuario siempre que tenga el link. 
Si hay algún regalo que quiera comprar tendrá un botón de "Me lo quedo" y se guardara en base de datos esa relación.
En el momento en que un regalo este asignado, el boton quedara puesto como "Asignado" y deshabilitado. Nunca dos personas diferentes pueden asignarse el mismo regalo

Tiene que existir la forma de registrarse, reestablecer la contraseña si hiciera falta y hacer logout. 

Todos los datos de usuario, regalos y asignaciones se guardaran en una Base de datos.
